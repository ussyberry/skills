# Resume Formatting Preferences

## Core Competencies Section
- **Layout:** 3 sets of 2 columns
- **Column Width:** 2.5 inches per column
- **Font Size:** 8pt for all items
- **Alignment:** All headers and bullet points must be single lines
- **No Word Wrapping:** Ensure all text fits within column boundaries
- **Spacing:** Proper padding between columns (10pt right padding)

## Bullet Points
- **All bullet points must be single lines** - no wrapping to multiple lines
- **Left Indent:** 20pt
- **Bullet Indent:** 10pt
- **Font Size:** 9pt
- **Alignment:** Second line should align properly with first line

## General Formatting
- **Page Size:** Letter (8.5" x 11")
- **Margins:** 0.75" on all sides
- **Font:** Helvetica family
- **Colors:** 
  - Headers: #0066cc (blue)
  - Text: #333333 (dark gray)
  - Name: #1a1a1a (dark gray)
  - Contact: #4a4a4a (medium gray)

## Section Order
1. Header (Name, Contact Info)
2. Professional Summary
3. Professional Experience
4. Education
5. Certifications
6. Security Clearance
7. Core Competencies (moved to end)

## Key Requirements
- **Canadian Standards:** No personal details (age, marital status, photo)
- **Maximum Pages:** 2 pages
- **Clean, Professional Layout**
- **Emphasis:** Government of Canada Reliability Security Clearance
- **CRA Job Date:** January 2023 – Present (continuous employment)
